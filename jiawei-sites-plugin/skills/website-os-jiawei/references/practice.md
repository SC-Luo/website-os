# 網站專業檢查

依網站用途選用，不把所有問題變成固定表單。先看使用者最需要完成的任務，設計資訊次序、清楚標題、真實信任依據和明確行動；參考少量相關網站時分開來源觀察、AI 推論和使用者決定，不照抄品牌。

- **內容**：列使用者真正會問的問題與站內位置；來源有效性、日期、授權及缺口要可追溯。不要虛構成功案例或客戶評價。
- **視覺與素材**：規劃圖片與版位後再定稿，檢查桌機／手機裁切、替代文字、失敗時保留版面；來源素材不可冒充真實情境。動畫須有用途，支援減少動態，不能阻礙操作。
- **互動**：測導覽、表單的輸入、成功、失敗、重試和焦點；涉及付款、預約或資料保存須實測與營運責任一致，不以展示畫面冒充真實交易。
- **品質與交付**：檢查語意、對比、鍵盤、窄版溢出、載入、主要連結；必要時檢查安全、隱私、搜尋索引、備份及恢復。區分實際結果與工具限制，必要失敗不能由其他分數抵銷。
- **維護**：確認網站帳號與所有權、誰更新、誰收通知、成本、撤銷存取和故障處理；沒有確認就標示待決。
