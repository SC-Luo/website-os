# Website OS｜嘉偉老師版

**從網站想法開始，陪你規劃內容、製作網站、檢查成果到後續交接。**

Website OS 嘉偉老師版是一套以繁體中文溝通的網站製作技能。你可以先描述自己的品牌、服務或想做的事，不需要一開始就準備好完整規格；技能會協助整理需求，再使用可用的 **ChatGPT Sites** 建立或修改網站。

此版號為 **0.2.0**，依 Website OS 0.1.6 的方法整理，與原版分開維護；本版加入網站美感設計選擇流程及隨附設計參考庫。

## 適合誰使用？

- 想做個人品牌、工作室、商家或服務介紹網站的人。
- 想建立課程介紹、活動頁、作品集或簡單資訊網站的人。
- 已有 Sites 網站，希望修改內容、調整頁面或檢查使用體驗的人。
- 協助客戶製作網站，需要整理需求、確認範圍與交接事項的人。

實際能做的功能取決於你的需求、Sites 當時支援的能力與帳號權限。涉及預約、付款、客戶資料或後台的網站，需要另外確認功能、資料處理及營運責任。

## 這個技能會做什麼？

| 階段 | 技能協助的事情 |
| --- | --- |
| 1. 了解需求 | 釐清網站要給誰看、想達成什麼、訪客接下來要做什麼，以及已有的內容和素材。 |
| 2. 提出建議 | 根據需求整理頁面內容、視覺方向、必要功能、維護方式與可能的費用或時程影響。 |
| 3. 確認方向 | 將需要決定的範圍與重要選擇說清楚，取得你的確認；已有明確授權的部分直接接續。 |
| 4. 準備素材 | 在版面定稿前規劃圖片的用途、位置、來源與使用權；需要生成圖片時，記錄提示詞及實際工具。 |
| 5. 使用 Sites 建站 | 透過環境中可用的 Sites 工具建立或修改網站，並依實際回應確認保存、預覽與發布狀態。 |
| 6. 檢查與修正 | 依網站需求檢查畫面、內容、連結、互動與適用的手機、鍵盤及其他操作情境，清楚區分已測與未測。 |
| 7. 交接 | 說明網站網址、可見對象、編輯和維護方式，以及尚待處理的事項。 |

已有網站的小修改會沿用既有設計與決定，不必每次重新走完整的新站規劃。技能不會把未知資料編成已確認的事實，也不會把展示功能當作已驗證的真實交易或營運功能。

## 網站美感設計如何運作？

本版整合你的 `web-design-selector` 設計選擇方法，並隨附 74 種網站設計參考。製作新網站或重大視覺改版時，技能會根據網站用途、受眾、品牌與操作需求篩選方向，提出三種選擇及一種建議，讓你選定後再進行設計；你也可以明確委託它代選。

選定後會整理專案的設計規範，讓色彩、字體、版面和手機顯示有一致依據。已有品牌規範或指定設計風格時會優先採用；例行修改則沿用原有設計，不必重選。

參考庫來自 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)，套件附有來源及 MIT 授權聲明。它提供的是設計參考，不代表可直接使用原品牌商標、圖片或專有字體。

## 如何開始？

在已能使用此技能與 Sites 的環境中，可以直接說：

> 使用 Website OS 嘉偉老師版，幫我規劃並用 Sites 製作我的網站。

也可以附上你的初步想法，例如：

> 我經營一間美甲工作室，想做一個網站介紹服務和作品，讓客人了解如何預約。請先幫我整理需要準備的內容，再規劃網站。

開始時有以下資料會有幫助；沒有也可以先討論：

- **網站用途**：你想介紹什麼，希望訪客採取什麼行動。
- **對象**：主要希望誰看到這個網站。
- **內容與素材**：品牌名稱、服務說明、聯絡方式、照片、Logo 或參考網站。
- **限制**：預算、希望完成的時間、誰負責更新，以及是否需要預約等功能。

技能會先查閱可取得的資料，再詢問會影響方向的缺口。若需選擇重要的功能、範圍或商業條件，會先向你說明。

## 需要什麼環境？

本外掛提供網站工作流程與專業檢查指引，**不包含 Sites 服務本身**。要實際用 Sites 建站，需要在支援的 ChatGPT／Codex 環境中能夠使用 Sites，並具備相應權限。若 Sites 無法使用，技能會說明缺口，繼續完成當下能做的規劃；改用其他建站方式前會先取得你的同意。

外掛資料夾內含：

```text
jiawei-sites-plugin/
├── plugin.json                              外掛資訊
├── README.md                                本說明
└── skills/website-os-jiawei/
    ├── SKILL.md                             技能工作流程
    └── references/
        ├── practice.md                      按需使用的專業檢查指引
        ├── design-selection.md              美感設計選擇流程
        └── design-library/                  74 種設計參考及授權
```

## 下載與安裝

本版位於 GitHub 的 `codex/jiawei-sites-edition` 分支，外掛根目錄是 `jiawei-sites-plugin/`。**下載整個分支的 ZIP 會連同原版倉庫一起下載**；若使用需要外掛 ZIP 的匯入方式，應將 `jiawei-sites-plugin` 資料夾內的內容打包，讓 `plugin.json` 與 `skills/` 位於 ZIP 根目錄。

不同 ChatGPT／Codex 環境提供的匯入、安裝和管理方式可能不同，請依 [OpenAI 外掛封裝文件](https://developers.openai.com/plugins/build/plugins)及[外掛上傳與提交說明](https://developers.openai.com/plugins/deploy/submission)操作。提交時可能需要具備相應帳號權限、發布身分和其他資訊；套件能下載不代表已安裝、上架或通過審核。
